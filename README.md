# Instructions for basic editing

Except if you feel like you know what you are doing, you should just edit markdown (.md) files. You can easily find instructions online for writing markdown, but it should be quite intuitive and you can just follow the examples of what's already in exising pages
You can:
- add a post in _posts by creating a new file which starts with the post name (follow previous examples)
- edit the main page by editing 'index.md'
- edit the ressource page by editing 'ressources.md'
